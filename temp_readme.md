# 🏙️ Redesigning Craigslist Mumbai for Enhanced Usability

## 📌 Project Overview

**Goal:** Modernize Craigslist’s outdated interface into a fast, intuitive, and **mobile-first classifieds platform** tailored for Mumbai’s high-mobile user base.

The redesign enhances usability and engagement while preserving Craigslist’s **core identity and simplicity**.

---

## 🚧 Usability Challenge

The existing Craigslist suffers from:

- ❌ Non-functional search filters  
- ❌ Poor location management  
- ❌ Cluttered, outdated interface  

---

## 🔍 Key Findings (Heuristic Evaluation)

| Heuristic | Issue | Severity | Impact |
|----------|-------|----------|--------|
| **H3: User Control** | Hard to change location | 3 | High bounce rate |
| **H7: Efficiency of Use** | Broken filters | 4 | Blocks core tasks |
| **H8: Minimalist Design** | Cluttered homepage | 1 | Cognitive overload |

---

## 💡 Design Highlights

### 🎯 Core Principles

- 📱 **Mobile-First Design** — Fast-loading, touch-optimized layouts  
- 🎯 **Fitts’ Law** — Large, easy-to-tap buttons  
- 🧾 **Card Interface** — Clean listings for all devices  

### ✨ Key Improvements

- 🔎 **Enhanced Search & Filters** — Persistent search bar + chip filters  
- 🧭 **Intuitive Navigation** — Simplified categories & icons  
- 📍 **Location Selector** — Fixed, visible, and error-tolerant  
- ⚡ **Performance** — Fluid grids & responsive assets for speed and SEO
